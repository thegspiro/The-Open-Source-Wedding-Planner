How It Works

1. Set up a reverse proxy -- Point a domain (e.g., wedding.mydomain.com) to this application using nginx, Caddy, Apache, or Cloudflare Tunnel. Enable HTTPS.
2. Enter your public URL above -- This tells the embed codes where to point.
3. Copy embed codes -- Paste the iframe snippets into your website builder (Squarespace, WordPress, Wix, etc.) using their HTML/embed block feature.
4. Guests interact directly -- RSVP submissions, form data, and all interactions go directly to your server. You own the data.
